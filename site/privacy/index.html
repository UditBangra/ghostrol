Privacy

Updated 19 November 2026. Applies to the Ghostrol browser extension and ghostrol.com.

Ghostrol collects nothing. It makes no network requests, has no analytics, no crash reports, no account and no remote settings. Nothing you type or click is sent anywhere by Ghostrol.

What the extension does with your input

On Xbox Cloud Gaming pages, Ghostrol turns your keyboard and mouse into controller input inside the page. That input goes to the game the same way a real controller's would, and nowhere else. Ghostrol does not record or keep it.

What it keeps in your browser

These are stored with Chrome's extension storage on your computer. If Chrome sync is on, Chrome syncs the first three to your other computers, as it does for other extension settings. Ghostrol has no server, so none of it reaches us.

WhatWhy
Your presetsThe key layouts you make or change.
Your settingsMouse, display and shortcut preferences.
Per-game choices Which preset you picked for a game, and whether to use Ghostrol in games with their own mouse support.
Recent games Titles you played lately, shown in the popup. Kept on this computer only.
A play count Used once, to ask for a rating after a few sessions. Kept on this computer only.

In the Ghostrol Studio you can save a backup of it and delete your presets. Removing the extension removes all of it from your browser.

Permissions

  • storage, to keep the items above.
  • Access to Xbox Cloud Gaming pages only (xbox.com/play and play.xbox.com), to provide the controller there. Ghostrol does not run on any other site.

Reporting a problem

Report a problem in the popup opens a new GitHub issue in your browser with the Ghostrol version, browser, game and preset filled in. You see all of it, and nothing is sent unless you submit the issue yourself on GitHub, under GitHub's own privacy terms.

If you remove Ghostrol

Chrome opens ghostrol.com/uninstalled once, asking why you removed it. The address carries no information about you, and the page records nothing. If you choose a reason, it opens a GitHub form that is only sent if you submit it yourself.

This website

ghostrol.com uses no cookies, no analytics and no trackers, and loads nothing from other sites. It is hosted on Vercel, which, like any web host, handles the technical details of each request (such as your IP address) to deliver the page and keep it secure.

Children

Ghostrol collects no personal information from anyone, including children.

Changes

If this ever changes, this page will say so first, with the date above. The source code is public, so anyone can check what Ghostrol does.
