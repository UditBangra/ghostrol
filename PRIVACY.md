# Privacy

Ghostrol collects nothing.

- It makes no network requests. There are no analytics, no crash reports, no accounts and no remote settings.
- Your keyboard and mouse input is turned into controller input inside the page and goes nowhere else.
- Your settings and presets are stored in your browser. If Chrome sync is on, Chrome syncs them to your other computers the way it syncs other extension settings.
- It only runs on Xbox Cloud Gaming pages (`xbox.com/play` and `play.xbox.com`). Its only permission is `storage`.
- The list of recent games stays on your computer and is only used to show you that list.

The source code is public, so you can check all of this yourself.

The full policy is at https://ghostrol.com/privacy. Questions: open an issue on the GitHub repository.
