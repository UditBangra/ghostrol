Ghostrol is removed

Your presets and settings went with it. Nothing was kept anywhere else.

If you have a minute, tell us why. Pick the closest reason and GitHub opens a short form with it filled in. You need a GitHub account to send it, and you see everything before it is posted.

  • A game did not play rightTell us which one. A wrong layout is usually a quick fix.
  • The mouse felt wrongToo fast, too slow, drifting or jumpy aim.
  • It felt slow or laggyInput arriving late, or the popup taking long to open.
  • Setting up keys was confusingPresets, the Studio or the controls panel.
  • I switched to something elseA controller, another extension or another service.
  • I only wanted to try itNothing wrong, you were just looking.
  • Something elseWrite it in your own words.

Changed your mind?

Add Ghostrol again from the Chrome Web Store. If a game played badly, the issue list may already have a fix or a better preset.
