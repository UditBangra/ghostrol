Questions

How do I play Xbox Cloud Gaming with a keyboard and mouse?

Add Ghostrol to Chrome, open xbox.com/play and start a game. Ghostrol shows the game a controller and loads keys made for it. Click the game to capture your mouse, and press Esc to release it.

Is Ghostrol free?

Yes. There is no trial, no account and no payment screen. The code is open source under the GNU GPL, version 3.

Does it work with every xCloud game?

Every game in the Xbox Cloud Gaming library gets a layout for its genre, and popular games such as Forza Horizon, Call of Duty, Helldivers 2 and Cyberpunk 2077 have presets made for them. You can change any key in the Studio.

What about games that already support keyboard and mouse, like Fortnite?

Ghostrol steps aside in those games so the two never fight. You can still choose Ghostrol for one of them if you prefer it.

Does it add input lag?

No noticeable lag. Xbox Cloud Gaming reads the controller every 4 milliseconds, and Ghostrol answers each read in a few microseconds.

Does Ghostrol collect any data?

No. It makes no network requests, has no analytics and runs only on Xbox Cloud Gaming pages. Your presets stay in your browser.

Does it work in Microsoft Edge?

Yes. In Edge, allow extensions from other stores when it asks, then add Ghostrol from the Chrome Web Store.
