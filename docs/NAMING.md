# Name

The product is called **Ghostrol**, chosen by the owner on 2026-10-26.

Ghost plus control: a controller that is not really there. The game sees an Xbox pad, but your hands are on a keyboard and mouse. It is one coined word and easy to say. A web search on 2026-10-26 found nothing else using it. A trademark search (USPTO, EUIPO) is still worth doing before the store launch.

Store title pattern: `Ghostrol: Keyboard and Mouse for Xbox Cloud Gaming`.

The name lives in three files: `src/shared/brand.ts`, `public/_locales/en/messages.json` and `package.json`. Preset and backup files use the formats `ghostrol.preset` and `ghostrol.backup`; files saved under the earlier working name `fauxpad.*` still import.

## Earlier options

The code first shipped as **Fauxpad**, a working name. Other candidates were Clackpad, Thumbless, Padgeist and Wasdrift. Rejected after checking: Keymancer (too close to IOGEAR KeyMander) and Ghoststick (too close to KontrolFreek's "Ghost" thumbsticks). Ghostpad and similar ghost names were dropped because existing products already use them.
