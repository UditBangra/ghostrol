# Security

Ghostrol runs inside xbox.com and handles keyboard and mouse input, so security reports matter a lot.

## Reporting a problem

Please report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what an attacker could do, the steps to reproduce it, and the Ghostrol version. You will get an answer within a week.

## What counts

- Anything that lets a web page, another extension or a stranger read your input, change your presets or settings, or run code in the extension.
- Anything that makes Ghostrol send data anywhere. It is built to make no network requests at all.

A game that plays wrong is a normal bug: use Report a problem in the popup.

## Updates

Fixes ship as a new version through the Chrome Web Store and Microsoft Edge Add-ons, which update installed copies on their own. Only the latest version gets fixes.

## Never trust messages about Ghostrol's store account

Nobody from Ghostrol will ask you to install a different build, enter a password, or sign in anywhere. Ghostrol is only published under its own store listings.
